# Глоссарий

Один термин на понятие. Отчёт использует русский столбец, код использует столбец идентификатора.

| Термин отчёта | English | Идентификатор | Определение |
|---|---|---|---|
| вершина | node | `NodeId` | Перекрёсток или точка разветвления дорожной сети |
| дуга | arc | `ArcId` | Направленный участок дороги между двумя вершинами |
| функция времени проезда | travel time function, TTF | `Ttf` | Периодическая кусочно-линейная функция: момент выезда на дугу → время её проезда |
| момент отправления | departure time | `departure` | Момент времени выезда из начальной вершины |
| время прибытия | arrival time | `arrival` | Момент достижения вершины при заданном отправлении |
| свойство FIFO | FIFO property | `fifo` | Более поздний выезд на дугу не даёт более раннего прибытия |
| шорткат | shortcut | `Shortcut` | Дуга иерархии, заменяющая путь через сжатые вершины |
| сжатие | contraction | `contract` | Удаление вершины с добавлением шорткатов, сохраняющих расстояния |
| кастомизация | customization | `customize` | Пересчёт весов шорткатов CCH под новую метрику без смены топологии |
