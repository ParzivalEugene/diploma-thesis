# Поиск маршрута на дорожных сетях с зависящими от времени весами

Научно-исследовательская работа бакалавра (НИТУ МИСИС, 7-й семестр): реализация на Rust и экспериментальное сравнение методов предобработки графа (TD-Dijkstra, TD-A\*, TCH, CATCHUp) на данных OpenStreetMap. Отчёт и презентация написаны на Typst.
